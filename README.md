# ATmega328PでグラフィックLCDの表示テスト
## Overview
AVRマイコンを使ってグラフィックLCDを制御するプログラムです。

## Files
Microchip studio 7.0で作りました。

atmega328_tg12864e_schematics.png : 回路図です。

## Parts
(U1)AVRマイコン ATmega328p	 

(LCD1) 128x64pixel グラフィック液晶モジュールTG12864

(CN1/CN2)ピンヘッダ・ピンソケット	 

(VR1/VR2)アナログジョイスティック  JT8P-3.2T-B10K-1-16Y

(VR3)半固定抵抗 10kΩ

(R1)抵抗  茶黒橙 10kΩ

(R2)抵抗  緑茶黒 51Ω

(CN3)ピンヘッダ  3x2pinピンヘッダ

(C1)積層セラミックコンデンサ 0.1μF

(SW1)スライドスイッチ。電源スイッチに使用

(D1)ショットキーバリアダイオード SD103A。昇圧回路に使用 

(L1)インダクタ 100μH。昇圧回路に使用

(U2)DC/DCコンバータ HT7750A。昇圧回路に使用

(C2)電解コンデンサ 100μF。昇圧回路に使用

スペーサ／ネジ／ナット

単三型アルカリ乾電池(1.5V)  	 

電池ボックス  単三型x2本
